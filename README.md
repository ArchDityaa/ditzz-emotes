# Ditzz | Emotes Hub

Script emote Roblox dengan full splash loading screen, wheel hijack, favorit, custom animation set, tema, dan HUD editor.

**Developer:** Ditzz

## Cara Menjalankan

Tempel kode ini di executor kamu:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/ArchDityaa/ditzz-emotes/main/Loader.lua"))()
```

atau langsung tanpa loader:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/ArchDityaa/ditzz-emotes/main/Emotes.lua"))()
```

## File

| File        | Fungsi                                              |
| ----------- | --------------------------------------------------- |
| `Loader.lua` | Loader kecil, mengambil `Emotes.lua` dari repo ini |
| `Emotes.lua` | Script utama (splash loading + emote hub)           |

## Kontrol (PC)

- Tekan `.` untuk buka/tutup menu emote.
